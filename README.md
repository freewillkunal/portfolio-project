# My Portfolio

A simple personal portfolio webpage built with HTML and an external CSS stylesheet, as part of the BCA (AI & Data Science) Web Development lab assignment.

## Project Structure
```
portfolio-project/
├── index.html
├── style.css
├── images/
│   └── profile.svg
└── README.md
```

## Features
- Semantic HTML (`header`, `nav`, `section`, `footer`)
- External CSS only (`style.css`), linked via `<link>` in `<head>`
- Consistent color theme (navy blue, light blue, orange accent) using HEX values
- Custom typography using the Google Font **Poppins**
- CSS Box Model used for spacing (margin, padding, border) between sections
- Styled navigation bar with hover effects
- Styled skills table with alternating row colors
- Project cards with box shadows
- Styled contact form with labeled fields and validation attributes (`required`)
- `position: sticky` used for the navigation header
- `position: fixed` used for the "Back to Top" button
- `<hr>` separators between sections
- Smooth scrolling for in-page navigation links

## How to View
Open `index.html` in any web browser. No build steps or dependencies required.

## Sections
1. **About Me** — profile image and short introduction
2. **My Skills** — table of technical skills and proficiency level
3. **My Projects** — cards showcasing sample projects
4. **Contact Me** — contact form (name, email, message)
